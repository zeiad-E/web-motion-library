# web-motion-library

A Claude Code skill: a reference library for websites with strong motion.

- **catalog.md**: ~100 web effects in 12 families (scroll, 3D/WebGL, media, typography, cursor, navigation, entrances, aesthetic, micro-interactions, data, sound, AI assets), each with what the visitor sees, how it's built, cost, audience impact and pitfalls
- **audience.md**: what motion does to people, fit by industry, when motion hurts, Arabic/RTL
- **ideas.md**: an idea engine for producing 20–100+ varied, strong ideas, with scoring and an output format
- **choreography.md**: turning many effects into one experience (thread object, handoffs, pacing, hero entrance)
- **tools.md**: stack choices and rough KB/ms budgets
- **recipes.md**: working code patterns and performance lessons

## Install

Clone into your personal skills folder:

```bash
git clone https://github.com/zeiad-E/web-motion-library ~/.claude/skills/web-motion-library
```

Any new Claude Code session will then use it when you ask for animation ideas or build motion-heavy pages.
